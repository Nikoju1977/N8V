09 · SAUVEGARDE + GUIDE

Comment démarrer ?

1. Touche ACTIVER AUDIO. 2. Appuie sur DRUMS ONLY pour tester la boîte à rythmes seule, ou sur PLAY pour lancer l'ensemble. 3. Change un patch synthé et les rythmes. 4. Active REC WAV pour capturer ton morceau.

Avec le clavier virtuel, joue un accord pour modifier l'arpégiateur principal ; avec LATCH, le dernier accord reste actif. Choisis CLAVIER pour jouer directement ou SÉQUENCEUR 64 pour lire la mélodie programmée.

Sauvegarder mes réglages

Sauver patch exporte un fichier JSON contenant les paramètres, séquences mélodiques, rythmique et basse. Importer patch recharge cette session. Les changements sont aussi mémorisés localement par ce navigateur.

MIDI + installation mobile

Le bouton MIDI recherche des périphériques via Web MIDI sur les navigateurs compatibles, comme Chrome de bureau sur HTTPS. L'accès MIDI peut être absent sur Safari/iOS. Pour installer en PWA, héberge le dossier complet sur HTTPS puis utilise la fonction « Installer » ou « Ajouter à l'écran d'accueil » du navigateur.

Limites de l'émulation

Cette application est une création originale inspirée de l'architecture du Moog Subsequent 37 : elle ne contient ni firmware, ni émulation officielle du circuit analogique Moog. Les pentes de filtres et le mode duo sont approchés numériquement. Les sorties CV, le traitement d'une entrée audio externe et certains paramètres avancés du synthétiseur physique ne sont pas reproduits.
